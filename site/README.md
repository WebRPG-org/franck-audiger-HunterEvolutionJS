# Website

The `site/` folder contains the PHP pages that present the project online, distribute builds, and collect player feedback.

## Main pages

- `index.php` – multilingual home page (French/English) with links to downloads and the web version of the game
- `release-note.php` – version history
- `bug-reports.php` – form for reporting bugs (stored server side in JSON)
- `feedback.php` – sends suggestions or general feedback
- `contact.php` – simple contact form
- `desktop/` and `android/` – download listings for each platform
- `lang.php` – small helper to manage the displayed language

Site icons and the `style.css` stylesheet are at the root of this folder.
